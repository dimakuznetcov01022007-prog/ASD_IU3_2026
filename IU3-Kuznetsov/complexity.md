# Расчёт асимптотики

n — длина массива, m — число столбцов матрицы. Операции с int считаем O(1).

| Задача | Время | Дополнительная память |
| --- | --- | --- |
| 1. Минимум и максимум | Θ(n) | Θ(1) |
| 2. Индекс первого вхождения | Θ(n) | Θ(1) |
| 3. Подсчёт вхождений | Θ(n) | Θ(1) |
| 4. Все индексы элемента | Θ(n) | Θ(1) |
| 5. Сумма на чётных позициях | Θ(n) | Θ(1) |
| 7. Второй максимум | Θ(n) | Θ(1) |
| 8. Фильтрация по знаку | Θ(n) | Θ(n) для хранения результата |
| 9. Проверка отсортированности | Θ(n) | Θ(1) |
| 10. Поиск элемента с условием | Θ(n) | Θ(1) |
| 25. Сумма элементов | Θ(n) | Θ(1) |
| 27. Сумма квадратов | Θ(n) | Θ(1) |
| 28. Медиана массива | Θ(n log n) из-за сортировки | Θ(1) |
| 49. Сумма строк матрицы | Θ(nm) | Θ(1) |

## Пояснения
**Задачи 1, 2, 3, 4, 5, 7, 8, 9, 10, 25, 27:** Это однопроходные алгоритмы. Цикл выполняется n раз, внутри — простые операции (сравнение, сложение). Время Θ(n). Дополнительная память: несколько переменных (Θ(1)).

**Задача 28:** Сначала сортируем массив, потом берем центральный элемент (или среднее двух). Время Θ(n log n) из-за сортировки, память Θ(1).

**Задача 49:** Два вложенных цикла (n и m). Внутренний цикл выполняется m раз для каждой из n строк. Время Θ(nm). Память Θ(1), так как сумму храним в переменной.
