# Отчёт по задаче 27

## Идея решения и выбор структуры данных
Числа хранятся в массиве `int[]`. Программа проходит по массиву, умножает каждый элемент на самого себя и прибавляет результат к общей сумме. 
Для суммы используется тип `long`.

## Асимптотика
- Время работы — `O(n)`, потому что каждый элемент обрабатывается один раз.
- Дополнительная память — `O(1)`, потому что используются только сумма и текущее число. Входной массив занимает `O(n)` памяти.

## Ручные тесты
1. `[2, 3]` → `13`. Проверяет обычный случай: `4 + 9 = 13`.
2. `[-2, 3]` → `13`. Проверяет, что квадрат отрицательного числа положительный.
3. `[1000, 1000]` → `2000000`. Проверяет большие числа.
