# Отчёт по задаче 7

## Идея решения и выбор структуры данных
Числа хранятся в массиве `int[]`. Программа делает два прохода. 
Первый проход находит максимум. Второй проход находит максимальный элемент, который строго меньше первого максимума — это и есть второй максимум.

## Асимптотика
- Время работы — `O(n)`, потому что выполняется два прохода по массиву, что в сумме даёт `O(2n) = O(n)`.
- Дополнительная память — `O(1)`, потому что используются две переменные для максимумов. Входной массив занимает `O(n)` памяти.

## Ручные тесты
1. `[5, 1, 9, 2]` → `5`. Проверяет обычный случай.
2. `[9, 8, 7]` → `8`. Проверяет убывающий массив.
3. `[1, 2, 3]` → `2`. Проверяет возрастающий массив.
