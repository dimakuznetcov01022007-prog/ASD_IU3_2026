# Отчет по задаче 7. Второй максимум

**1. Идея решения и структура данных:**
Два прохода: первый — поиск максимума, второй — поиск максимального элемента, который меньше первого максимума.

**2. Анализ асимптотики и обоснование кодом:**
- Время: Θ(2n) = Θ(n). Обоснование: два отдельных цикла `for` по n итераций.
- Память: Θ(1) — две переменные `max` и `secondMax`.

**3. Ручные тесты (граничные случаи):**
- `[5, 1, 9, 2]` → `5`.
- `[9, 8, 7]` → `8` (убывающий массив).
- `[1, 2, 3]` → `2` (возрастающий массив).
