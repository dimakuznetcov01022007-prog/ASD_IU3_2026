# Отчёт по задаче 49

## Идея решения и выбор структуры данных
Матрица хранится в двумерном массиве `int[][]`. Программа использует двойной цикл. 
Внешний цикл идёт по строкам, внутренний — по элементам строки. Для каждой строки сумма накапливается в переменной и выводится сразу после обработки строки.

## Асимптотика
- Время работы — `O(n * m)`, где `n` — количество строк, `m` — количество столбцов. Каждый элемент матрицы посещается один раз.
- Дополнительная память — `O(1)`, потому что используется одна переменная для суммы. Сама матрица занимает `O(n * m)` памяти.

## Ручные тесты
1. `[[1, 2], [3, 4]]` → `3 7`. Проверяет обычный случай.
2. `[[1, 2]]` → `3`. Проверяет матрицу из одной строки.
3. `[[1], [2], [3]]` → `1 2 3`. Проверяет матрицу из одного столбца.
4. `[[0, 0], [0, 0]]` → `0 0`. Проверяет матрицу из нулей.
