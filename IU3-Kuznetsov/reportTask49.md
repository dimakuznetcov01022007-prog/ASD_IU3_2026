# Отчет по задаче 49. Сумма строк матрицы

**1. Идея решения и структура данных:**
Двумерный массив `int[][]`. Двойной цикл: внешний по строкам, внутренний по элементам строки.

**2. Анализ асимптотики и обоснование кодом:**
- Время: Θ(nm). Обоснование: два вложенных цикла `for` — внешний `n` итераций, внутренний `m` итераций.
- Память: Θ(1) (кроме хранения самой матрицы).

**3. Ручные тесты (граничные случаи):**
- `[[1,2],[3,4]]` → `3 7`.
- `[[1, 2]]` → `3` (одна строка).
- `[[1], [2], [3]]` → `1 2 3` (один столбец).
- `[[0, 0], [0, 0]]` → `0 0` (все нули).
