# Отчёт по задаче 25

## Идея решения и выбор структуры данных
Числа хранятся в массиве `int[]`, потому что по условию дан массив целых чисел. 
Сначала сумма равна нулю. Затем программа один раз проходит по массиву и прибавляет каждое число к сумме. 
Для суммы используется тип `long`, потому что результат может не поместиться в тип `int`.

## Асимптотика
- Время работы — `O(n)`, где `n` — количество чисел в массиве. Программа просматривает каждый элемент один раз.
- Дополнительная память — `O(1)`, потому что для подсчёта нужны только сумма и счётчик цикла. Сам входной массив занимает `O(n)` памяти.

## Ручные тесты
1. `[1, 2, 3]` → `6`. Проверяет обычный случай с положительными числами.
2. `[-1, -2, -3]` → `-6`. Проверяет работу с отрицательными числами.
3. `[1000000000, 1000000000]` → `2000000000`. Проверяет, что сумма не переполняется.
