# Отчет по задаче 3. Подсчёт вхождений

**1. Идея решения и структура данных:**
Массив `int[]`. Счётчик `count` увеличивается при каждом совпадении.

**2. Анализ асимптотики и обоснование кодом:**
- Время: Θ(n). Обоснование: цикл `for (int i = 0; i < n; i++)` без `break` — всегда n итераций.
- Память: Θ(1) — одна переменная `count`.

**3. Ручные тесты (граничные случаи):**
- `[1, 2, 1, 3], 1` → `2` (несколько совпадений).
- `[1, 1, 1], 1` → `3` (все совпадают).
- `[1, 2, 3], 5` → `0` (нет совпадений).
