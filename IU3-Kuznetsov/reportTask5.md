# Отчет по задаче 5. Сумма на чётных позициях

**1. Идея решения и структура данных:**
Цикл с шагом 2 (`i += 2`), сумма в переменной.

**2. Анализ асимптотики и обоснование кодом:**
- Время: Θ(n/2) = Θ(n). Обоснование: цикл `for (int i = 0; i < n; i += 2)` — n/2 итераций.
- Память: Θ(1).

**3. Ручные тесты (граничные случаи):**
- `[1, 2, 3, 4, 5]` → `9` (нечётная длина).
- `[1, 2, 3, 4]` → `4` (чётная длина).
- `[10]` → `10` (один элемент).
