# Отчёт по задаче 5

## Идея решения и выбор структуры данных
Числа хранятся в массиве `int[]`. Программа начинает с индекса `0` и каждый раз увеличивает индекс на `2`: `0`, `2`, `4` и так далее. 
Числа на этих позициях прибавляются к сумме. Для суммы используется тип `long`, чтобы в неё мог поместиться большой результат.

## Асимптотика
- Время работы — `O(n)`. Программа смотрит примерно половину элементов, но их количество всё равно зависит от размера массива `n`.
- Дополнительная память — `O(1)`, потому что используется одна переменная для суммы. Входной массив занимает `O(n)` памяти.

## Ручные тесты
1. `[1, 2, 3, 4, 5]` → `9`. Складываются элементы `1`, `3` и `5`.
2. `[1, 2, 3, 4]` → `4`. Проверяет чётную длину массива.
3. `[10]` → `10`. Проверяет массив из одного элемента.
