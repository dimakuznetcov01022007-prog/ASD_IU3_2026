# Отчёт по задаче 2

## Идея решения и выбор структуры данных
Числа хранятся в массиве `int[]`. Программа идёт по массиву с начала и сравнивает каждый элемент с числом `x`. 
При первом совпадении возвращается индекс элемента. Если совпадений нет, возвращается `-1`.

## Асимптотика
- Время работы — `O(n)` в худшем случае, потому что иногда нужно проверить весь массив.
- Дополнительная память — `O(1)`, потому что новые массивы не создаются. Входной массив занимает `O(n)` памяти.

## Ручные тесты
1. Массив `[4, 8, 15, 16]`, `x = 15` → `2`. Проверяет, что элемент находится в середине.
2. Массив `[4, 8, 15]`, `x = 4` → `0`. Проверяет элемент в начале массива.
3. Массив `[1, 2, 3]`, `x = 100` → `-1`. Проверяет случай, когда числа нет в массиве.
