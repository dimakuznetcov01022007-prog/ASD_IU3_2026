# Отчёт по задаче 1

## Идея решения и выбор структуры данных
Числа хранятся в массиве `int[]`, так как по условию дан массив целых чисел. 
Сначала минимум и максимум равны первому элементу. Затем программа проходит по остальным элементам. 
Если найдено меньшее число, меняется минимум. Если найдено большее число, меняется максимум.

## Асимптотика
- Время работы — `O(n)`, потому что программа один раз проходит по массиву.
- Дополнительная память — `O(1)`, потому что используются только две переменные для минимума и максимума. Сам входной массив занимает `O(n)` памяти.

## Ручные тесты
1. `[3, 1, 7]` → `1 7`. Проверяет обычный случай.
2. `[5, 5, 5]` → `5 5`. Проверяет массив из одинаковых чисел.
3. `[-10, -2, -5]` → `-10 -2`. Проверяет работу с отрицательными числами.
4. `[100]` → `100 100`. Проверяет массив из одного элемента.
