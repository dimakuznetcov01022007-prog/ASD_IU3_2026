# Отчёт по задаче 28

## Идея решения и выбор структуры данных
Числа хранятся в массиве `int[]`. Программа сначала сортирует массив. 
Если длина массива нечётная, берётся центральный элемент. 
Если чётная — вычисляется среднее арифметическое двух центральных элементов, результат выводится как число с плавающей точкой.

## Асимптотика
- Время работы — `O(n log n)`, потому что используется сортировка массива.
- Дополнительная память — `O(1)`, потому что сортировка выполняется на месте (без создания новых массивов). Входной массив занимает `O(n)` памяти.

## Ручные тесты
1. `[3, 1, 2]` → `2`. Проверяет нечётную длину массива.
2. `[1, 2, 3, 4]` → `2.5`. Проверяет чётную длину массива.
3. `[5]` → `5`. Проверяет массив из одного элемента.
4. `[7, 7, 7, 7]` → `7.0`. Проверяет массив из одинаковых чисел.
