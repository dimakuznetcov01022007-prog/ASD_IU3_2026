# Отчет по задаче 28. Медиана массива

**1. Идея решения и структура данных:**
Сортируем массив. Для нечётной длины — `arr[n/2]`, для чётной — среднее `arr[n/2 - 1]` и `arr[n/2]`.

**2. Анализ асимптотики и обоснование кодом:**
- Время: Θ(n log n). Обоснование: `Arrays.sort` использует быструю сортировку/сортировку слиянием.
- Память: Θ(1) (сортировка на месте).

**3. Ручные тесты (граничные случаи):**
- `[3, 1, 2]` → `2`.
- `[1, 2, 3, 4]` → `2.5`.
- `[5]` → `5`.
- `[7, 7, 7, 7]` → `7.0`.
