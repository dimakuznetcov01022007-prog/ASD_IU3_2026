# Отчёт по задаче 4

## Идея решения и выбор структуры данных
Числа хранятся в массиве `int[]`. Программа проходит по массиву и выводит индекс каждого элемента, который равен `x`. Порядок вывода — возрастание индексов.

## Асимптотика
- Время работы — `O(n)`, потому что проверяется каждый элемент массива.
- Дополнительная память — `O(1)`, потому что вывод происходит сразу, без сохранения в массив. Входной массив занимает `O(n)` памяти.

## Ручные тесты
1. Массив `[1, 2, 1]`, `x = 1` → `0 2`. Проверяет несколько вхождений.
2. Массив `[1, 1, 1]`, `x = 1` → `0 1 2`. Проверяет, что выводятся все индексы.
3. Массив `[1, 2, 3]`, `x = 5` → пустой вывод. Проверяет случай без совпадений.
