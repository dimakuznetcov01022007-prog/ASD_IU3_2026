# Отчет по задаче 4. Все индексы элемента

**1. Идея решения и структура данных:**
Массив `int[]`. Выводим `i` при каждом совпадении.

**2. Анализ асимптотики и обоснование кодом:**
- Время: Θ(n). Цикл проходит по всем элементам, так как нет `break`.
- Память: Θ(1).

**3. Ручные тесты (граничные случаи):**
- `[1, 2, 1], 1` → `0 2`.
- `[1, 1, 1], 1` → `0 1 2`.
- `[1, 2, 3], 5` → пустой вывод.
