# Отчет по задаче 10. Поиск элемента с условием

**1. Идея решения и структура данных:**
Проходим по массиву, если `arr[i] % k == 0`, запоминаем индекс.

**2. Анализ асимптотики и обоснование кодом:**
- Время: Θ(n). Цикл без `break` проходит все элементы.
- Память: Θ(1) — одна переменная `lastIndex`.

**3. Ручные тесты (граничные случаи):**
- `[2, 4, 5, 6], k=2` → `3`.
- `[1, 3, 5], k=2` → `-1`.
- `[2, 4, 6], k=2` → `2` (все кратные).
