# Отчёт по задаче 10

## Идея решения и выбор структуры данных
Числа хранятся в массиве `int[]`. Программа проходит по массиву и проверяет, делится ли текущий элемент на `k` без остатка. 
Если да, запоминает его индекс. В конце выводится последний найденный индекс или `-1`.

## Асимптотика
- Время работы — `O(n)`, потому что проверяется каждый элемент массива.
- Дополнительная память — `O(1)`, потому что используется одна переменная для хранения индекса. Входной массив занимает `O(n)` памяти.

## Ручные тесты
1. `[2, 4, 5, 6]`, `k = 2` → `3`. Проверяет, что возвращается последний кратный элемент.
2. `[1, 3, 5]`, `k = 2` → `-1`. Проверяет случай без кратных элементов.
3. `[2, 4, 6]`, `k = 2` → `2`. Проверяет случай, когда все элементы кратны.
