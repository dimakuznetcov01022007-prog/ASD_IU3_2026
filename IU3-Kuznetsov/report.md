# Отчёт по ЛР1 (Кузнецов, группа 32)

## Задача 1. Минимум и максимум
**Идея:** Инициализируем min и max первым элементом. Проходим по массиву, обновляя значения.
**Асимптотика:** Время Θ(n), память Θ(1).
**Тесты:** `[3, 1, 7] → 1 7`.

## Задача 2. Индекс первого вхождения
**Идея:** Проходим по массиву с начала. При совпадении с target возвращаем индекс и выходим.
**Асимптотика:** Время Θ(n), память Θ(1).
**Тесты:** `[4, 8, 15], 15 → 2`.

## Задача 3. Подсчёт вхождений
**Идея:** Счетчик, который увеличивается при каждом совпадении.
**Асимптотика:** Время Θ(n), память Θ(1).
**Тесты:** `[1, 2, 1, 3], 1 → 2`.

## Задача 4. Все индексы элемента
**Идея:** Проходим по массиву и выводим индекс при каждом совпадении.
**Асимптотика:** Время Θ(n), память Θ(1).
**Тесты:** `[1, 2, 1], 1 → 0 2`.

## Задача 5. Сумма на чётных позициях
**Идея:** Цикл с шагом 2 (i = 0, 2, 4...). Складываем элементы.
**Асимптотика:** Время Θ(n), память Θ(1).
**Тесты:** `[1, 2, 3, 4, 5] → 9`.

## Задача 7. Второй максимум
**Идея:** Находим первый максимум. Затем ищем максимальный элемент, который меньше первого.
**Асимптотика:** Время Θ(n), память Θ(1).
**Тесты:** `[5, 1, 9, 2] → 5`.

## Задача 8. Фильтрация по знаку
**Идея:** Проходим по массиву и раскладываем элементы в два новых массива: положительные и отрицательные (нули пропускаем). Выводим оба массива.
**Асимптотика:** Время Θ(n), память Θ(n).
**Тесты:** `[-1, 2, 0, -3, 4] → полож: [2, 4], отриц: [-1, -3]`.

## Задача 9. Проверка отсортированности
**Идея:** Сравниваем текущий элемент с предыдущим. Если текущий меньше, массив не отсортирован.
**Асимптотика:** Время Θ(n), память Θ(1).
**Тесты:** `[1, 2, 3] → YES`.

## Задача 10. Поиск элемента с условием
**Идея:** Проходим по массиву, проверяя, кратен ли элемент k. Запоминаем индекс последнего совпадения.
**Асимптотика:** Время Θ(n), память Θ(1).
**Тесты:** `[2, 4, 5, 6], k=2 → 3`.

## Задача 25. Сумма элементов
**Идея:** Складываем все числа в одну переменную.
**Асимптотика:** Время Θ(n), память Θ(1).
**Тесты:** `[1, 2, 3] → 6`.

## Задача 27. Сумма квадратов
**Идея:** Возводим каждый элемент в квадрат и прибавляем к сумме.
**Асимптотика:** Время Θ(n), память Θ(1).
**Тесты:** `[2, 3] → 13`.

## Задача 28. Медиана массива
**Идея:** Сортируем массив по возрастанию. Если длина нечетная — берем центральный элемент. Если четная — среднее арифметическое двух центральных.
**Асимптотика:** Время Θ(n log n) из-за сортировки, память Θ(1).
**Тесты:** `[3, 1, 2] → 2`, `[1, 2, 3, 4] → 2.5`.

## Задача 49. Сумма строк матрицы
**Идея:** Двойной цикл. Внешний по строкам, внутренний по элементам строки. Сумма выводится сразу.
**Асимптотика:** Время Θ(nm), память Θ(1).
**Тесты:** `[[1,2],[3,4]] → 3 7`.
