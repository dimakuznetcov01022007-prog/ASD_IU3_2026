# Отчёт по задаче 8

## Идея решения и выбор структуры данных
Числа хранятся в массиве `int[]`. Создаются два новых массива: для положительных и для отрицательных чисел. 
Сначала программа считает, сколько будет положительных и отрицательных. Затем создаёт массивы нужного размера и заполняет их, сохраняя исходный порядок.

## Асимптотика
- Время работы — `O(n)`, потому что выполняется два прохода по массиву.
- Дополнительная память — `O(n)`, потому что создаются два новых массива, суммарный размер которых равен `n` (без учёта нулей).

## Ручные тесты
1. `[-1, 2, 0, -3, 4]` → положительные: `[2, 4]`, отрицательные: `[-1, -3]`. Проверяет обычный случай и игнорирование нулей.
2. `[1, 2, 3]` → положительные: `[1, 2, 3]`, отрицательные: `[]`. Проверяет отсутствие отрицательных.
3. `[-1, -2, -3]` → положительные: `[]`, отрицательные: `[-1, -2, -3]`. Проверяет отсутствие положительных.
