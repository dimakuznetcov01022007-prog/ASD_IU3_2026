# Отчёт по задаче 9

## Идея решения и выбор структуры данных
Числа хранятся в массиве `int[]`. Начиная со второго элемента, программа сравнивает каждый элемент с предыдущим. 
Если следующий элемент меньше предыдущего, массив не отсортирован. Если таких элементов нет, массив отсортирован по неубыванию.

## Асимптотика
- Время работы — `O(n)` в худшем случае, потому что может потребоваться проверить весь массив.
- Дополнительная память — `O(1)`, потому что новые массивы не создаются. Входной массив занимает `O(n)` памяти.

## Ручные тесты
1. `[1, 2, 3]` → `YES`. Проверяет массив с возрастающими числами.
2. `[3, 2, 1]` → `NO`. Проверяет нарушение порядка в начале.
3. `[1, 1, 1]` → `YES`. Проверяет, что одинаковые соседние числа разрешены (неубывающий массив).
